# 探栏

中文名：**探栏** · 前缀 `probe` · 端口 **8100**

## 骨架（新骨）

**传感报文装载 → 标定/质控门槛入栏 → 站点汇总物化 → 坏点旁路 → 栏账互证**

| 对比 | 潮切 | 对拍 | **本仓** |
| --- | --- | --- | --- |
| 拓扑 | 事件时入窗→关窗 | 双轨对齐 | **质控门槛入栏→站点汇总** |
| 在途 | 入窗缓冲 | 悬账 | **入栏缓冲（过门槛未汇总）** |
| 产物 | 窗切片 | 对齐差+结论 | **站点汇总账** |
| 旁路 | 迟到匣 | 悬账缺边 | **坏点匣（未过门槛）** |

皮：环境监测传感站（大气/水质探头）。去皮：**标定质控门槛 + 入栏 + 汇总物化 + 坏点旁路 + 栏贯验**。  
禁止做成运维工单、告警大屏、传感器 CRUD。禁止抄潮切窗号/对拍左右轨命名。

## 页面

## 栏号解析真源（站键精确物化包）

- 真源唯一：`app/services/栏号解析.py`。封包把 `站点键 → 栏号` 固化为不可变版本，带 sha256 指纹；绑定/改名一律换版，旧版保留可回放。
- 写读同一站键解析：装载写库按行钉 `解析指纹`，结栏按写入栏号分组不二次解析；重名站（同名不同源键）各落各栏，不串邻站栏。
- 站名模糊解析只准进**只读归档**（`/api/栏号解析/模糊归档`），`按站名模糊回刷` 永远硬拒；齐套对账只认站键精确命中。
- 批次可显式钉 `解析指纹`，未知指纹硬拒（HTTP 400），杜绝改名瞬间双解析串栏；并发写走 `BEGIN IMMEDIATE` + 退避重试。
- 四页（栏规列表、报文流、入栏缓冲、站点汇总账）顶部真源卡可见同一真源；切流后锁指纹、拒回刷，面板灯与齐套实值对齐。
- 争用复跑：`python3 -I backend/并发改名争用.py [数据目录] [轮次]`；端到端冒烟：`python3 -I backend/冒烟_重名全链.py`。
